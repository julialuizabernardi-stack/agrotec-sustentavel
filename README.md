# 🌾 Projeto Agrinho - Site Interativo e Animado

Este repositório contém a estrutura de um site moderno, colorido e dinâmico feito para o **Programa Agrinho**, destacando pilares importantes como sustentabilidade, tecnologia e cidadania de forma lúdica.

## 🚀 Estrutura dos Arquivos Incluídos

* **`index.html`**: A estrutura principal da página contendo os textos explicativos, seções estruturadas via cards e o mini-quiz interativo.
* **`style.css`**: Estilização rica usando o conceito de *Glassmorphism* (cartões translúcidos), cores harmônicas que misturam tons de natureza com tecnologia, e a folha de animação de fundo.
* **`script.js`**: Mecanismo inteligente responsável por gerar dinamicamente as partículas flutuantes do fundo colorido, gerenciar as pop-ups informativas e validar as respostas do quiz escolar.
* **`README.md`**: Este guia explicativo do projeto.

## 🎨 Funcionalidades em Destaque

1.  **Fundo Colorido Animado**: Partículas coloridas mimetizando folhas e raios de sol sobem suavemente pela tela sem quebras de performance.
2.  **Design Responsivo**: Se adapta perfeitamente a computadores, tablets e smartphones.
3.  **Janelas Modais Dinâmicas**: Clique nos cards de conteúdos para ver mais detalhes abrindo uma caixinha animada na tela.
4.  **Quiz Interativo**: Resposta imediata para fixação do conhecimento ecológico dos alunos.
